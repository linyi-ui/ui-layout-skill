# 2个网站首屏颜色反差 · 6 个设计点

对应抖音视频：拆 2 个风格完全相反的网站首屏（建筑3D展示站 + 番茄品牌页脚站），6 个设计点逐一还原

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说一句话让 AI 做，往往会漏掉这些让画面更讲究的细节。

---

## 01 衬线大字压天空（Serif Title Over Sky）
常见写法：做个大标题 → AI 把标题放在安全区域，不会主动叠加背景图，也不会选衬线字体

```
标题用衬线字体，顶格对齐屏幕上边缘，
占屏幕宽度 90% 以上；
允许和背景图叠加，不许加文字底色块或半透明遮罩。
```

## 02 九成淡色+一处高饱和点缀（90% Muted + One Accent）
常见写法：做个配色方案 → AI 常见做法是好几种颜色一起上，互相抢视线

```
主色只用 2 个低饱和色（如米黄、蓝灰），饱和度压低；
留 1 处高饱和强调色，只能用在一行小字或一个图标上，
不许在其他任何地方再出现第二处高饱和色。
```

## 03 树枝镂空露材质（Branch Cutout With Depth）
常见写法：加个装饰图案 → 常见是贴一张平面纹理图糊弄过去，没有真实深度

```
外立面用不规则树枝状镂空结构，
镂空后面要露出阳台、绿植等真实场景内容；
镂空边缘要有阴影和材质厚度感，体现是立体结构不是贴图。
```

## 04 照片当背景色（Photo As Background Color）
常见写法：做个背景色块 → AI 给一块纯色或渐变色，比较单薄

```
背景用一张贴合主题的微距/实拍照片铺满色块区域，
不许用纯色或渐变色；
不许叠加纯色滤镜或渐变遮罩压掉照片细节。
```

## 05 超粗圆体无衬线标题（Ultra Bold Rounded Sans）
常见写法：做个粗体标题 → AI 常给常规无衬线字体，棱角分明，不会特意选圆体

```
标题用超粗圆角无衬线字体，字重拉到 900，
笔画所有转角做圆角处理，不许出现尖锐棱角。
```

## 06 品牌名弧形排布（Arc Text Layout）
常见写法：做个品牌名展示 → 容易直接用 textPath 强行弯曲字形本身，导致字母被压扁拉伸变形

```
品牌名文字沿一条向上拱起的弧线排列，弧度适中；
文字字形保持正常比例，不许被拉伸变形扭曲；
可搭配一个圆润图标装饰放在弧形下方。
```

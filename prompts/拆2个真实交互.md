# 拆2个真实交互 · 3 个设计点

对应抖音视频：拆2个有真实交互效果的网站（意大利CGI工作室Anubi + 纽约广告代理商Red Antler），3 个设计点逐一还原

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说一句话让 AI 做交互，往往会漏掉"因果反馈"这层设计逻辑。

---

## 01 按住触发物理反馈（Press-and-Hold Physics）
常见写法：加个炫酷效果 → AI 常给悬停变色或简单的粒子漂浮，没有"按住-释放"的因果反馈

```
用 WebGL 粒子系统组成初始文字/图形；
鼠标按住时粒子向外扩散炸开，
松手后重新聚合成另一个 3D 形态（不是简单归位原样）；
不许做成单纯的颜色变化或缩放特效。
```

## 02 同模型换材质（Material Swap on Same Model）
常见写法：做个材质切换 → 常见是直接切换成另一个完全不同的模型，成本高还容易穿帮

```
用同一个3D模型（造型不变），
设计2套风格反差明显的材质方案（如冷色金属 vs 暖色毛绒+尖刺）；
场景切换时材质实时过渡，不许直接切换成另一个模型本身。
```

## 03 点击筛选重排（Filter-and-Reflow）
常见写法：做个分类筛选 → 常见是点击分类后直接跳转新页面或整页刷新，白屏闪烁一下

```
点击分类标签后，不符合条件的卡片直接隐藏，
剩余卡片用动画重新排列填补空隙，
整个过程控制在 0.3-0.5 秒内完成，不许跳转页面或整页刷新。
```

# 拆一个好看的首屏 · 3 个设计点

对应抖音视频：拆一个 35mm 胶片相机站的首屏，3 个设计点逐一还原

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个高级的首屏"，AI 多半会把颜色和元素全堆上来。

---

## 01 配色极度克制（2 Colors Only）
常见写法：做个高级的首屏 → 颜色全堆上来，蓝色按钮、彩色卡片一起上，精密感没了

```
整屏只用 2 个颜色：背景 #0A0A0A（近黑），
主色 #FFFFFF（白）；强调色 #D98E3C（琥珀）
只允许出现 1 次，用在一个小标签上。
不许加渐变、不许加第二处彩色、不许加阴影发光。
```

## 02 标题顶满边缘（Edge-to-Edge Type）
常见写法：做个大标题 → 规规矩矩缩在屏幕中间，没有视觉冲击力

```
主标题占屏幕宽度 90% 以上，单行，
允许右侧被屏幕边缘裁切，不许为了完整显示而缩小；
字体选择笔画粗细均匀的无衬线特粗体
（字重 900），裁切后依然清晰可读。
```

## 03 线稿3D模型不填色（Wireframe 3D）
常见写法：放一张产品实拍照片 → 信息对但缺少参与感和精密仪器感

```
主视觉用 3D 线框模型（WebGL），只画轮廓线，
不许填色、不许加光影贴图，可随鼠标缓慢旋转；
左上角加一组等宽字体的参数读数（如帧率/分辨率），
营造精密仪器说明书的感觉。
```

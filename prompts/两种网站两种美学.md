# 两种网站两种美学 · 6 个设计点

对应抖音视频：拆 2 个风格完全相反的真实网站——年度回顾站（Better Off，极致克制）+ 辣味零食站（Henrietta Said，极致张扬），各 3 个设计点逐一还原。

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

一个靠克制、一个靠张扬，都好看。关键在于：每个"反常规"的排版决定背后都有一句能讲清楚的理由。

---

## CASE 01 年度回顾站（极致克制）

### 01 标题当锚点（Anchor Title）
常见写法：做长页面标题 → AI 常让整行标题跟着内容滚走，滚两屏就消失，用户失去坐标

```
做一个年度回顾长页面，
顶部放一行超大标题，滚动时固定不动（position sticky），
标题里只有年份随滚动进度递减，
照片在标题下方自由排布向上滚过，
要求：标题始终是视觉锚点，不许整行跟着滚走。
```

### 02 错落照片墙（Scatter Wall）
常见写法：排照片墙 → AI 常做成等宽等高的规整网格，一眼就是"商品目录"，失去松弛感

```
把照片做成错落瀑布流，
每张图宽高比和尺寸都不同，纵向位置上下随机错开约120px，
不要对齐成规整网格，留白宽松，
营造随手翻相册的松弛感，
要求：错而不乱，视线能顺着往下走。
```

### 03 框架无彩（Mono Frame）
常见写法：做"高级黑白风" → AI 常忍不住给按钮/链接加一点品牌色，反而和照片抢视线

```
整个页面框架严格黑白，
文字纯黑 #0a0a0a，背景纯白 #ffffff，不许给框架任何彩色，
所有颜色只来自照片本身，
按钮、线条、标签都用黑白灰，
要求：框架越克制，照片的色彩越突出。
```

## CASE 02 辣味零食站（极致张扬）

### 04 大字当背景（Type as Background）
常见写法：做产品页 → AI 常把产品居中、文字规规矩矩放旁边，谁也不突出

```
做零食产品页，
用一个超大的风味名（如KIMCHI）当整屏背景，字高占屏约70%，
产品包装袋叠在大字上方、允许被字边缘裁切，
字和产品用同色系微差，
要求：大字是绝对主角，产品只需露脸。
```

### 05 整屏换色（Full-screen Swatch）
常见写法：做系列展示 → AI 常把所有成员挤成一排小卡片，每个都没存在感

```
按口味分屏，
每个口味占满整屏，用一个专属背景色（泡菜红/辣鸡深红/水牛橙/柠椒黄），
滚动到下一屏时整屏背景色硬切换，
每屏结构一致只换色和文字，
要求：像翻一张张色卡，节奏明快。
```

### 06 小报营养版（Tabloid Nutrition）
常见写法：做营养成分表 → AI 常放一张标准黑白表格了事，毫无个性

```
把营养成分表做成小报版式，
红黄高饱和撞色，标题用超大全大写无衬线（像爆料头条），
信息排成报纸栏目，配“BREAKING NEWS”式小标，
数据表保留但加粗描边，
要求：枯燥信息也要有品牌态度。
```

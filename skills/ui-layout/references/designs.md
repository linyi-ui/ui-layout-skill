# 设计点库

每条固定格式：场景、要点、参数、❌ 什么时候不用、常见错误、提示词。

---

## 01 配色极度克制（2 Colors Only）

**场景**：想要"精密仪器感"、冷静高级的产品首屏、官网、工具类落地页。
**要点**：整屏只用背景色和主文字色两个颜色；强调色（第三种颜色）只允许出现一次，用在信息密度最低的地方（如小标签），不用在按钮或大面积区域——按钮是功能，颜色一多就会跟标题抢视线；标签是"眼睛的休息点"，不打断阅读顺序。
**参数**：背景 `#0A0A0A`（近黑）；主色 `#FFFFFF`（白）；强调色 `#D98E3C`（琥珀）只出现 1 次；不加渐变、不加第二处彩色、不加阴影发光。
**❌ 什么时候不用**：品牌本身调性活泼多彩（如儿童类、潮玩类）；电商类页面需要用颜色突出促销信息、折扣标签；页面内容本身依赖色彩分类（如数据可视化、分类标签墙）。
**常见错误**：一句话让 AI "做个高级的首屏"，AI 常见产出是颜色全堆上来（蓝色按钮、彩色卡片、渐变背景一起上），精密感瞬间就没了。

```
整屏只用 [2 个颜色]：背景 #0A0A0A（近黑），
主色 #FFFFFF（白）；强调色 #D98E3C（琥珀）
只允许出现 [1 次]，用在一个小标签上。
[不许加渐变、不许加第二处彩色、不许加阴影发光]。
```

## 02 标题顶满边缘（Edge-to-Edge Type）

**场景**：想要主标题本身成为画面视觉主体，而不是规规矩矩缩在屏幕中间一行小字。
**要点**：主标题占屏幕宽度 90% 以上、单行显示，允许右侧（或任意一侧）被屏幕边缘裁切，不为了显示完整而缩小字号；人眼看到"文字被边缘切断"会自动在脑子里补全，这个过程比看完一整行字更抓注意力，真要显示完整反而显得平淡像抄模板；字体要选笔画粗细均匀的无衬线特粗体（字重 900），这样裁切后依然好认。
**参数**：占宽比 ≥90%；字重 900；允许裁切（通常裁右侧，裁掉不超过 1 个字母/1 个汉字的宽度，不能裁到看不出是什么词）；字体无衬线、笔画均匀。
**❌ 什么时候不用**：标题文字本身很长、裁切会丢失关键信息（如法律声明、价格数字）；品牌名必须完整露出（法务/品牌规范要求）；多语言场景下不同语言长度差异大，裁切规则难以统一适配。
**常见错误**：一句话让 AI 做大标题，AI 往往把标题放大后仍然完整显示、规规矩矩缩在屏幕中间，没有这种"顶满甚至溢出"的视觉冲击力。

```
主标题占屏幕宽度 [90% 以上]，单行，
[允许右侧被屏幕边缘裁切]，不许为了完整显示而缩小；
字体选择 [笔画粗细均匀的无衬线特粗体]
（字重 900），裁切后依然清晰可读。
```

## 03 线稿3D模型不填色（Wireframe 3D）

**场景**：想要科技感、精密感的产品/主视觉展示，又想要比静态照片更强的参与感和互动感。
**要点**：主视觉用 3D 线框模型（WebGL），只画轮廓线不填色，可随鼠标缓慢旋转；照片是"看完就过去"的静态信息，线框模型能跟手互动，让人停下来多玩几秒；不填色是故意的，一填色就变成普通产品图，精密仪器的气质就没了；左上角可以加一组等宽字体的参数读数（如帧率、分辨率）做点缀，配合线稿强化"精密仪器说明书"的感觉。
**参数**：渲染方式线框 WebGL；不填色、不加光影贴图；可随鼠标缓慢旋转；点缀用等宽字体的参数读数（非讲解重点，不强求用户看懂具体数字）。
**❌ 什么时候不用**：产品本身需要强调真实材质和质感（如美食、服装、化妆品，线框模型传递不出这些信息）；没有 3D 建模资源或预算，临时拿现成模型凑数效果会很差；用户需要立刻看清产品真实长相（如电商详情页首图）。
**常见错误**：直接放一张产品实拍照片当主视觉——信息是对的，但缺少参与感和精密感；或者做了 3D 模型却填满了颜色和材质贴图，变成了普通产品渲染图，失去了"线稿"本身的克制感。

```
主视觉用 [3D 线框模型]（WebGL），只画轮廓线，
[不许填色、不许加光影贴图]，可随鼠标缓慢旋转；
左上角加 [等宽字体的参数读数]（如帧率/分辨率），
营造精密仪器说明书的感觉。
```

## 04 衬线大字压天空（Serif Title Over Sky）

**场景**：建筑、地产、人文类主视觉，想要标题本身带一点古典气质，和背景实景图融为一体而不是浮在上面的独立元素。
**要点**：标题用衬线字体，顶格对齐屏幕上边缘，字号占屏幕宽度 90% 以上；允许标题和背景图（天空、建筑等）直接叠在一起，不加文字底色块或半透明遮罩去"保护"文字可读性——这种叠加本身就是设计语言，强行加遮罩反而破坏融合感；衬线字比无衬线字多一分建筑/人文气质，适合和真实场景图直接对话。
**参数**：衬线字体；顶格对齐屏幕上边缘；占宽比 ≥90%；不加底色块、不加遮罩。
**❌ 什么时候不用**：背景图本身杂乱、对比度不足，叠加文字会导致可读性问题；品牌调性是现代科技感而非人文建筑感（衬线字会显得不搭）；需要高无障碍可读性的场景（如政务、金融类强制易读性要求）。
**常见错误**：一句话让 AI 做大标题，AI 大概率把标题放在屏幕中间的安全区域，不会主动让文字和背景图叠加，也不会特意选衬线字体。

```
标题用 [衬线字体]，[顶格对齐屏幕上边缘]，
占屏幕宽度 [90% 以上]；
[允许和背景图叠加]，不许加文字底色块或半透明遮罩。
```

## 05 九成淡色+一处高饱和点缀（90% Muted + One Accent）

**场景**：想要整体克制高级、但又不想完全黑白，希望有一点点"呼吸感"的彩色落点。
**要点**：整屏绝大部分面积（背景、主体）用两个低饱和主色，饱和度压得很低；只留一个元素（通常是一行小字、一个图标）用高饱和强调色，这是全图唯一的鲜艳色，其余任何地方都不许再出现第二处高饱和色；这个手法和"配色极度克制"（设计点01）的区别是：01 是黑白+强调色的极简骨架，05 是两个自然低饱和色（如米黄、蓝灰）打底，色彩更柔和、更适合实景图场景。
**参数**：两个低饱和主色（如米黄、蓝灰）打底；一处高饱和强调色，只用在一行文字或一个小图标上；不许在按钮、卡片、装饰线等第二处使用高饱和色。
**❌ 什么时候不用**：页面需要用颜色做信息分类（数据可视化、标签分类页）；电商类页面需要用高饱和色突出促销信息，多处强调色是刚需。
**常见错误**：一句话让 AI 做配色，AI 常见做法是好几种颜色一起上，互相抢视线，没有"克制"和"唯一点缀"的概念。

```
主色只用 [2 个低饱和色]（如米黄、蓝灰），饱和度压低；
留 [1 处高饱和强调色]，只能用在一行小字或一个图标上，
[不许在其他任何地方再出现第二处高饱和色]。
```

## 06 照片当背景色（Photo As Background Color）

**场景**：想要某个色块区域（页脚、卡片背景、大色块板块）比纯色更有质感，又不想做复杂的图形设计。
**要点**：不用纯色色块或 CSS 渐变去填充背景，而是用一张贴合主题的微距/实拍照片铺满整个区域，让照片本身承担"背景色"的角色；照片自带的光泽、颗粒、反光比纯色多一层真实质感，看起来更贵；关键是不许在照片上叠加纯色滤镜层或渐变遮罩去"统一色调"，那样会压掉照片本身的细节，变成了变相的纯色块。
**参数**：背景用贴题微距/实拍照片铺满色块区域；不叠加纯色滤镜、不叠加渐变遮罩；照片本身的光泽/颗粒细节要保留可见。
**❌ 什么时候不用**：没有高质量的贴题照片素材，临时找一张不搭的图效果会很差；页面需要强对比度的纯色背景做视觉分区（照片细节会干扰分区识别）；品牌调性是极简科技风，照片质感和调性冲突。
**常见错误**：一句话让 AI 做背景，AI 大概率给一块纯色或渐变色，比较单薄；或者用了照片但叠加了一层半透明色块"统一风格"，结果照片细节全被糊掉，等于没用。

```
背景用 [一张贴合主题的微距/实拍照片] 铺满色块区域，
不许用纯色或渐变色；
[不许叠加纯色滤镜或渐变遮罩压掉照片细节]。
```

## 07 品牌名弧形排布（Arc Text Layout）

**场景**：想要品牌名/标题比直排多一点俏皮感、活泼感，适合带幽默调性或亲和力的品牌（食品、生活方式、潮玩类）。
**要点**：文字沿一条向上拱起的弧线排列，像拱门造型，中间高两边低；弧度要适中，不能弯曲过度导致单字变形或难以阅读；文字本身的字形要保持正常比例，不许因为跟随弧线而被拉伸压扁扭曲——弧形排布动的是"排列路径"，不是"字形本身"，这是容易踩的坑；常搭配一个圆润的图标或装饰元素放在弧形下方强化俏皮感。
**参数**：文字沿弧线排列，弧度适中；字形保持正常比例不变形；常搭配圆润图标装饰。
**❌ 什么时候不用**：品牌调性严肃正式（金融、法律、医疗类，弧形排布显得不够庄重）；文字内容较长，弧形排布会导致两端字母挤压变形难以阅读；需要严格遵循品牌视觉规范（VI 手册通常要求品牌名水平直排）。
**常见错误**：一句话让 AI 做弧形文字，常见翻车点是直接用 CSS/SVG 的 textPath 强行弯曲字形本身，导致字母被压扁拉伸变形，可读性变差；正确做法是排列路径弯曲、字形本身保持正常比例。

```
品牌名文字沿 [一条向上拱起的弧线] 排列，弧度适中；
[文字字形保持正常比例，不许被拉伸变形扭曲]；
可搭配一个圆润图标装饰放在弧形下方。
```

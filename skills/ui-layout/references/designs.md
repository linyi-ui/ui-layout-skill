# 设计点库

每条固定格式：场景、要点、参数、❌ 什么时候不用、常见错误、提示词。

---

## 01 配色极度克制（2 Colors Only）

**场景**：想要"精密仪器感"、冷静高级的产品首屏、官网、工具类落地页。
**要点**：整屏只用背景色和主文字色两个颜色；强调色（第三种颜色）只允许出现一次，用在信息密度最低的地方（如小标签），不用在按钮或大面积区域——按钮是功能，颜色一多就会跟标题抢视线；标签是"眼睛的休息点"，不打断阅读顺序。
**参数**：背景 `#0A0A0A`（近黑）；主色 `#FFFFFF`（白）；强调色 `#D98E3C`（琥珀）只出现 1 次；不加渐变、不加第二处彩色、不加阴影发光。
**❌ 什么时候不用**：品牌本身调性活泼多彩（如儿童类、潮玩类）；电商类页面需要用颜色突出促销信息、折扣标签；页面内容本身依赖色彩分类（如数据可视化、分类标签墙）。
**常见错误**：一句话让 AI "做个高级的首屏"，AI 常见产出是颜色全堆上来（蓝色按钮、彩色卡片、渐变背景一起上），精密感瞬间就没了。

```
整屏只用 [2 个颜色]：背景 #0A0A0A（近黑），
主色 #FFFFFF（白）；强调色 #D98E3C（琥珀）
只允许出现 [1 次]，用在一个小标签上。
[不许加渐变、不许加第二处彩色、不许加阴影发光]。
```

## 02 标题顶满边缘（Edge-to-Edge Type）

**场景**：想要主标题本身成为画面视觉主体，而不是规规矩矩缩在屏幕中间一行小字。
**要点**：主标题占屏幕宽度 90% 以上、单行显示，允许右侧（或任意一侧）被屏幕边缘裁切，不为了显示完整而缩小字号；人眼看到"文字被边缘切断"会自动在脑子里补全，这个过程比看完一整行字更抓注意力，真要显示完整反而显得平淡像抄模板；字体要选笔画粗细均匀的无衬线特粗体（字重 900），这样裁切后依然好认。
**参数**：占宽比 ≥90%；字重 900；允许裁切（通常裁右侧，裁掉不超过 1 个字母/1 个汉字的宽度，不能裁到看不出是什么词）；字体无衬线、笔画均匀。
**❌ 什么时候不用**：标题文字本身很长、裁切会丢失关键信息（如法律声明、价格数字）；品牌名必须完整露出（法务/品牌规范要求）；多语言场景下不同语言长度差异大，裁切规则难以统一适配。
**常见错误**：一句话让 AI 做大标题，AI 往往把标题放大后仍然完整显示、规规矩矩缩在屏幕中间，没有这种"顶满甚至溢出"的视觉冲击力。

```
主标题占屏幕宽度 [90% 以上]，单行，
[允许右侧被屏幕边缘裁切]，不许为了完整显示而缩小；
字体选择 [笔画粗细均匀的无衬线特粗体]
（字重 900），裁切后依然清晰可读。
```

## 03 线稿3D模型不填色（Wireframe 3D）

**场景**：想要科技感、精密感的产品/主视觉展示，又想要比静态照片更强的参与感和互动感。
**要点**：主视觉用 3D 线框模型（WebGL），只画轮廓线不填色，可随鼠标缓慢旋转；照片是"看完就过去"的静态信息，线框模型能跟手互动，让人停下来多玩几秒；不填色是故意的，一填色就变成普通产品图，精密仪器的气质就没了；左上角可以加一组等宽字体的参数读数（如帧率、分辨率）做点缀，配合线稿强化"精密仪器说明书"的感觉。
**参数**：渲染方式线框 WebGL；不填色、不加光影贴图；可随鼠标缓慢旋转；点缀用等宽字体的参数读数（非讲解重点，不强求用户看懂具体数字）。
**❌ 什么时候不用**：产品本身需要强调真实材质和质感（如美食、服装、化妆品，线框模型传递不出这些信息）；没有 3D 建模资源或预算，临时拿现成模型凑数效果会很差；用户需要立刻看清产品真实长相（如电商详情页首图）。
**常见错误**：直接放一张产品实拍照片当主视觉——信息是对的，但缺少参与感和精密感；或者做了 3D 模型却填满了颜色和材质贴图，变成了普通产品渲染图，失去了"线稿"本身的克制感。

```
主视觉用 [3D 线框模型]（WebGL），只画轮廓线，
[不许填色、不许加光影贴图]，可随鼠标缓慢旋转；
左上角加 [等宽字体的参数读数]（如帧率/分辨率），
营造精密仪器说明书的感觉。
```

## 04 按住触发物理反馈（Press-and-Hold Physics）※ 跨界案例：偏交互，和 ui-motion 有交集

**场景**：技术型工作室（3D/WebGL/引擎开发）想证明自己的技术实力，又不想堆砌文案自夸。
**要点**：用粒子系统组成一个文字或图形，鼠标按住时粒子向外扩散炸开，松手后粒子不是简单归位，而是重新聚合成另一个 3D 形态（比如从文字变成一个旋转的几何体）；核心逻辑是"做给你看"比"说给你听"更有说服力——让用户亲手操作、感受到真实的物理反馈，比写一百句技术介绍都管用；聚合成"另一个新形态"而不是原样归位，是制造惊喜感的关键，原样归位会显得单薄。
**参数**：粒子系统构成初始文字/图形；按住时向外扩散；松手后聚合成不同于原始状态的新形态（如文字→3D几何体）；不做成简单的颜色变化或缩放。
**❌ 什么时候不用**：品牌调性偏商务严肃、用户以中老年或非技术群体为主（交互成本高，可能没人会去尝试按住）；移动端触屏场景下"按住"手势不如桌面端直觉（需要额外的交互提示引导）。
**常见错误**：一句话让 AI 做炫酷效果，常见做法是加一个悬停变色或简单的粒子漂浮动画，没有"按住-释放"这种需要用户主动操作、有明确因果反馈的交互设计。

```
用 [WebGL 粒子系统] 组成初始文字/图形；
鼠标 [按住时粒子向外扩散炸开]，
[松手后重新聚合成另一个 3D 形态]（不是简单归位原样）；
不许做成单纯的颜色变化或缩放特效。
```

## 05 同模型换材质（Material Swap on Same Model）※ 跨界案例：偏交互，和 ui-motion 有交集

**场景**：品牌官网的首屏 3D 主视觉，想用一套模型讲两种不同的品牌故事/调性，不想为每种调性单独建模。
**要点**：用同一个 3D 模型（造型、拓扑完全不变），设计两套风格反差明显的材质方案（比如冷色金属质感 vs 暖色毛绒+尖刺混合材质），场景切换或滚动触发时让材质实时过渡；核心逻辑是"换材质比换模型成本低得多，但调性反差可以做到和换模型一样大"——同一个鹿角造型，金属质感传递的是硬核科技感，毛绒+尖刺传递的是柔软又带锐利的反差感，用户记住的是"反差"本身，而不是具体换了什么。
**参数**：同一套模型/造型不变；设计 2 套材质方案，风格要形成明显反差（冷色系 vs 暖色系、硬质感 vs 软质感等）；场景切换时材质需要实时过渡（不是硬切）；不许直接切换成另一个模型。
**❌ 什么时候不用**：品牌只有一种调性诉求，不需要在同一屏呈现反差；模型造型本身比较复杂，材质大幅切换会导致渐变过程中出现违反物理直觉的诡异过渡效果；性能敏感场景（移动端低端设备）实时材质渲染成本较高。
**常见错误**：一句话让 AI 做材质切换，常见做法是直接切换成另一个完全不同的模型（成本高、容易穿帮衔接不自然），而不是保留同一套造型只换材质属性（更省成本、过渡也更自然）。

```
用 [同一个 3D 模型]（造型不变），
设计 [2 套风格反差明显的材质方案]（如冷色金属 vs 暖色毛绒+尖刺）；
场景切换时 [材质实时过渡]，不许直接切换成另一个模型本身。
```

## 06 点击筛选重排（Filter-and-Reflow）※ 跨界案例：偏交互，和 ui-motion 有交集

**场景**：案例/作品数量多且分类杂的网站（代理商官网、电商分类页），想让用户在不离开当前页面的情况下快速对比某一类内容。
**要点**：点击顶部分类标签后，不符合条件的卡片直接隐藏，剩余卡片用动画重新排列填补空隙，整个过程控制在 0.3-0.5 秒内完成，不许有明显的加载等待；这是用"标签筛选"代替"跳转子页面"的设计逻辑——传统做法是点击分类后跳转到一个新页面，用户要点"返回"才能看其他分类，而就地筛选让用户不离开当前上下文就能连续切换对比多个分类，大幅减少点击和等待次数。
**参数**：点击分类标签触发筛选；不符合条件的卡片隐藏；剩余卡片动画重新排列补位；整个过程 0.3-0.5 秒完成；不跳转页面。
**❌ 什么时候不用**：分类本身需要承载大量独立信息（如电商商品页需要展示价格、库存等详情），单纯隐藏/显示卡片不足以呈现完整信息，跳转详情页反而更合理；内容总量很少（少于10条）时，筛选的意义不大，直接全部展示即可。
**常见错误**：一句话让 AI 做分类筛选，常见做法是点击分类后直接跳转新页面或刷新整个列表（白屏闪烁一下），没有"原地隐藏+动画补位"这种丝滑的过渡体验。

```
点击 [分类标签] 后，不符合条件的卡片 [直接隐藏]，
剩余卡片 [用动画重新排列填补空隙]，
整个过程控制在 [0.3-0.5 秒] 内完成，不许跳转页面或整页刷新。
```

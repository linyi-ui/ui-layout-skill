# 反模板感自检清单

交付排版前逐条检查，排除"一眼就是 AI 默认排版"的典型问题。

## 配色

- [ ] 页面里出现的颜色种类数了一遍，确认在 2-3 种以内（背景/主文字 + 最多 1 种强调色）
- [ ] 强调色没有同时出现在超过 1 个地方（按钮、标签、图标如果都用了强调色，说明没控制住）
- [ ] 没有为了"显得丰富"加渐变、加阴影发光、加多层叠加的颜色

## 主次

- [ ] 整屏只有一个最大的视觉焦点，其他元素的字号/颜色/位置都明显比焦点弱
- [ ] 标题、按钮、卡片不是"大小差不多、颜色差不多"的平均主义排布
- [ ] 导航、辅助说明文字确实退到了视觉次要位置（变小、变淡、靠边），不是喊着跟主体抢视线

## 留白

- [ ] 页面不是"塞满了内容凑数据密度"，重点区域前后有明显的呼吸空间
- [ ] 留白区域不是"不知道放什么就空着"，而是有意图地衬托旁边的内容

## 具体与可执行

- [ ] 给出的排版建议/描述词里有具体色号、具体占比数字、具体字重数字，不是"好看一点""高级一点"这种无法执行的模糊词
- [ ] 每一处"反常规"的决定（裁字、留超大空白、不填色）都能用一句话说出设计理由

## 常见"一眼AI感"的典型问题（避免）

- 标题规规矩矩居中缩在画面中间一小块，没有占满宽度的冲击力
- 按钮、卡片、图标统一套用某个 UI 库的默认圆角/阴影/配色，缺乏针对本次内容的定制
- 为了"看起来高级"加了大量发光、渐变、玄幻光效，结果显得廉价而不是高级
- 整屏信息密度均匀分布，没有主次节奏，像在填表格
